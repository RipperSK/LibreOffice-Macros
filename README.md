# LibreOffice-Macros

This repo stores a small collection of LibreOffice macros I developed mostly with the help of https://claude.ai to save some time.
Feel free to use and modify as per MIT License.

# Macro files short summary

- CleanBankExport.bas this is a BASIC macro for LibreOffice Calc that filters and hides out uninteresting columns and rows of a Tatrabanka XLS export. Hiding is done for columns and filtering for rows.
